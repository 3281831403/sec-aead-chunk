攻击者把两个加密文件的分块互换拼接，解密端照单全收，拼出来的明文完全合法：每块必须绑定块序号与总块数，末块必须带有标记且不能被截断；块顺序打乱必须拒绝，块重复拼接必须拒绝，附加认证数据必须包含上下文的全部字段。任何解密失败都只能以统一错误类型对外呈现，批量解密时每条消息必须各自独立。系统的不变量是：任意重排、截断或拼接都被拒绝，同一明文两次加密得到的密文不同且都能解开。
